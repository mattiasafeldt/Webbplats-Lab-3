# Norrgläntan
Responsiv webbplats med information om naturupplevelser, aktiviteter samt kontaktuppgifter.
## Om projektet
Webbplatsen är byggd med **HTML** och **CSS** utifrån wireframes och mockuper för mobil och desktop.
## Tekniker
- **HTML** för sidans struktur.
- **CSS** för färger, layout och typografi.
- **Flexbox** och **Grid** för placering av innehåll.
- **Media queries** för anpassning till olika skärmstorlekar.
## Filstruktur
- css/style.css - Stilmall för webbplatsen
- images/ - Bilder och logotyper
- index.html - Innehåll för webbplatsen
- README.md - Information kring projektet
